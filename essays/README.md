# Essays — Strategic & Philosophical Considerations

Essays on the positioning, philosophy, and strategic reading of PSA — texts about *why it
exists, who it is for, and what it means*, rather than how the engine works (for that, see the
[PSA-core README](../README.md), [API.md](../API.md), and [FIELD_GUIDE.md](../FIELD_GUIDE.md)).

Each essay is bilingual (`.en.md` / `.it.md`) and ends with a **PSA self-analysis appendix**:
the essay body is run through PSA's own classifiers before publication, and the real numbers
(alert, ABI, BHS, dominant postures) are pasted in. The folder's thesis is that opinions
produced by a language model need an external meter — so each essay applies that meter to
itself.
